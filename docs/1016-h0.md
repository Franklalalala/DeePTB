# `1016-h0`: H0 prior

This branch, based on `1016-gf`, removes repeated and unneeded work from the H0
prior of the UniTB route. Tables, cutoffs, the FFT grid, the NUFFT accuracy and
the PBE functional are unchanged, and every computation keeps a single code
path. Block keys are the same as on `1016-gf`. The local-potential blocks
differ by summation order only (rounding level); the periodic field is
unchanged bit for bit.

## Local potential

| Step | Change |
| --- | --- |
| Tile incidences | Each atom image enumerates only the tiles of the box spanned by its cutoff sphere, sqrt(r_c^2 + 1e-12), and each candidate is tested point by point with the support test of the AO values. Images that only touched a tile's bounding sphere are dropped (6 % fewer incidences, 12 % fewer GEMM flops at 1,024 TePb atoms); their AO values in the tile were all zero. |
| AO values | One Triton kernel evaluates each radial channel once per point and image and the real harmonics in Cartesian form, (-1)^\|m\| N_lm P_l^(\|m\|)(z/r) Re/Im((x + i y)/r)^\|m\| (no atan2, cos or sin), and writes A and A v in the same pass. |
| Block scatter | One Triton kernel adds each image-pair block of the GEMM output to its key (binary search, atomic add) only in the orientation whose key code is not above the reverse one; the reverse keys receive the transposes at the end, so V_ji(-R) = V_ij(R)^T exactly. Onsite blocks (i, i, 0) are symmetrised by the final Hermitisation. |

## Field

- The radial transforms of the local potential, the valence density and the
  core charge are evaluated only at the distinct |G| of the charge sphere:
  78,630 instead of 199,788 magnitudes at 1,024 TePb atoms, and up to 7.6 times
  fewer in low-symmetry cells, where this step dominated the field.
- The Hartree term uses `torch.where` instead of boolean indexing, and the
  inverse transform of the density that only fed a finiteness check is gone.
- The NUFFT plan is still kept only for grids up to 256^3 points: keeping larger
  plans would hold 19 GiB (432^3 grid) or 38 GiB (540^3) of device memory
  between calls, and consecutive structures rarely share a grid.
  cufinufft allocates the plan outside PyTorch (about 256 bytes per grid point);
  when the free device memory is below that estimate (grids from about 600^3
  points on one H200, after an earlier call), the PyTorch cache is released
  first.

## Host synchronisation and finish

Validation values are read back once per step, the gauge tables are uploaded
once, the stream synchronisation after the NUFFT is gone (the plan runs on the
current stream), the PBE derivatives differentiate views of their inputs
instead of copies, and the finish step gathers the reverse blocks once for both
the residual and the Hermitisation.

At 1,024 atoms the H0 prior splits into the field (677 → 601 ms), the local
potential (1,111 → 468 ms), the nonlocal part (60 → 64 ms), the two-centre
tables (13 ms) and the finish step (57 → 54 ms). The remaining field time is
mostly the PBE potential (autograd), the NUFFT and the transforms. On 17 library cells
(28–78 atoms, mostly low symmetry, where the radial transforms dominated) the
field is 1.2–4.6 times faster (median 1.9; for example 729 → 159 ms for a
38-atom cell with a 240^3 grid) and the whole H0 prior 1.4–3.9 times (median 1.7). GF / H0 rises
because only the H0 prior changed; Flash stays 1.15 times faster than UniTB at
16 atoms, where both routes are dominated by the model, and 2.4–3.1 times faster
from 250 atoms up. The H0 prior varies by 10–20 % between cards, so ratios are
only compared within one card.

Throughput of UniTB with four processes under MPS on one card: 11,871
structures per hour on the 16–432-atom mix (8,924 on `1016-gf`) and 6,657 per
hour on 40 distinct compositions, each seen for the first time (4,349).
