# DeePTB contribution guide

See [Contributing to DeePTB](../CONTRIBUTING.md) for this maintenance branch's
workflow, architecture, style, and testing requirements.

Start with a concrete issue or proposed improvement. Search the
[issue tracker](https://github.com/Franklalalala/DeePTB/issues) for related work
and include enough input and environment detail to reproduce bugs.

Develop the change on a branch based on `1006-stable`. Include relevant
behavioral tests and documentation, then open a pull request targeting
`Franklalalala/DeePTB:1006-stable`. Use a draft while implementation or required
validation is incomplete.

Describe the problem, resulting behavior, compatibility implications, and
validation results. Address review feedback and required CI checks before
merging. Keep changes focused enough to review independently.
