These FP64 reference vectors were exported from actual built-in ABACUS
`xc/xc_spin/gcxc/gcx_spin/gcc_spin` calls at commit
`ee99e3ca7f64f7c3b33cc6b68bc0bb99ef16599f`, PBE `use_libxc=false`.
They are not generated by h0rebuild or a LibXC reference helper.

Spin columns: rho, zeta, gradient_up (gradient_down = gradient_up/2),
local_vup, local_vdown, exchange_v1up, exchange_v1down, exchange_v2up,
exchange_v2down, correlation_v1up, correlation_v1down, correlation_v2.
Scalar columns: rho, sigma, local_v, correction_v1, correction_v2.
Potentials and derivatives are in Hartree atomic units. `v2` multiplies
the density gradient in the flux, whereas LibXC `vsigma` needs a factor 2.

The density and polarization grid spans local/correction cutoffs, uniform
density, near/full/over polarization, and both magnetization signs.
Local and exchange comparisons use tight numerical bounds. Correlation is
explicitly an approximate smooth-formula comparison (rtol 1e-5, atol 2e-7),
with exact zero-branch checks; it is not proof of global mathematical
equivalence. Full structure H/S acceptance limits remain unchanged.

Exporter and complete reference patch/identity are retained in the round-4
review evidence (`round4_reference_parts.sh`, `reference_builtin_parts.patch`).
